HY2单协议 v8
改进点：永久关闭外部网站误重启探针；保留v7全部提速、ping0国家命名和断线后台安装功能。v7原版不修改。

唯一安装命令：
command -v curl >/dev/null 2>&1 || { export DEBIAN_FRONTEND=noninteractive; apt-get update -y && apt-get install -y --no-install-recommends ca-certificates curl; };if command -v curl >/dev/null 2>&1;then u='https://raw.githubusercontent.com/marceldun/cheatcode/main/install_fast_proxy_v8.sh';f=/tmp/install_fast_proxy_v8.sh;rm -f "$f";for x in "$u" "https://ghfast.top/$u" "https://gh-proxy.com/$u";do curl -4fL --connect-timeout 10 --max-time 180 --retry 3 "$x" -o "$f"&&[ -s "$f" ]&&break;done;if [ -s "$f" ];then bash "$f";else echo '下载失败，请重新粘贴同一命令';fi;fi

Xshell因代理重启断开时无需重跑。重新连接后：
cat /root/sb-fast-v8-install.done
显示0代表成功。节点信息：sb-fast info

v8行为：
- 从零安装不创建任何外部网站健康检查timer。
- 从v7升级会沿用HY2密码。
- v5-v7旧timer先备份，再永久mask。
- sing-box真实退出仍由systemd Restart=always自动恢复。
- 安装阶段仍执行一次真实联网测试，但安装完成后不会定时访问Google并重启服务。
