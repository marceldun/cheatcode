HY2单协议极限提速 v7
改进点：删除Reality和自动分发，只保留HY2；启用内核支持的最高级QUIC参数；ping0.cc检测国家；生成小火箭国家旗帜节点。

唯一安装命令
command -v curl >/dev/null 2>&1 || { export DEBIAN_FRONTEND=noninteractive; apt-get update -y && apt-get install -y --no-install-recommends ca-certificates curl; };if command -v curl >/dev/null 2>&1;then u='https://raw.githubusercontent.com/marceldun/cheatcode/main/install_fast_proxy_v7.sh';f=/tmp/install_fast_proxy_v7.sh;rm -f "$f";for x in "$u" "https://ghfast.top/$u" "https://gh-proxy.com/$u";do curl -4fL --connect-timeout 10 --max-time 180 --retry 3 "$x" -o "$f"&&[ -s "$f" ]&&break;done;if [ -s "$f" ];then bash "$f";else echo '下载失败，请保持窗口打开后重新粘贴同一条命令';fi;else echo '系统软件源无法安装curl，请检查VPS本身是否能联网';fi

使用
1. 把上面完整一行粘贴到VPS，按一次回车。
2. 代理重启造成Xshell断开时不用重跑，后台仍会继续。
3. 重新连接后输入：cat /root/sb-fast-v7-install.done
4. 显示0代表安装、真实联网、持续传输和ping0.cc国家检测全部成功。
5. 输入 sb-fast info，复制唯一的 hysteria2:// 链接到小火箭。
6. 节点显示格式：国旗 国家名 纯净独享IP，例如：🇺🇸 美国 纯净独享IP。

说明
- 国家名由VPS直接访问 https://ipv4.ping0.cc/geo 或 https://ping0.cc/geo 获得。
- “纯净独享IP”是按用户要求写入的固定节点标签，ping0.cc地理接口不验证IP是否纯净或独享。
- 云厂商安全组需要允许脚本最终显示的UDP端口。
- v6原文件保留；v7会沿用v6的HY2密码并停止v5/v6旧健康探针。
