REALITY 极限吞吐版 v11（完整新建副本）
协议组合：VLESS + RAW/TCP + REALITY + XTLS Vision
改进点：移除v10的16KB TCP未发送队列限制，扩大自适应TCP窗口，强制Vision零缓冲策略，启用GRO/GSO/TSO网卡卸载并提高Xray调度优先级。v10脚本、配置和文档原样保留。

唯一安装/升级命令：
u='https://raw.githubusercontent.com/marceldun/cheatcode/main/install_fast_reality_v11.sh';f=/tmp/install_fast_reality_v11.sh;rm -f "$f";if ! command -v curl >/dev/null 2>&1&&! command -v wget >/dev/null 2>&1;then if command -v apt-get >/dev/null 2>&1;then apt-get update -y&&apt-get install -y curl ca-certificates;elif command -v apk >/dev/null 2>&1;then apk add --no-cache curl ca-certificates;elif command -v dnf >/dev/null 2>&1;then dnf -y install curl ca-certificates;else yum -y install curl ca-certificates;fi;fi;for x in "$u" "https://ghfast.top/$u" "https://gh-proxy.com/$u";do if command -v curl >/dev/null 2>&1;then curl -4fL --connect-timeout 10 --max-time 180 --retry 3 "$x" -o "$f";else wget -T 180 -O "$f" "$x";fi&&[ -s "$f" ]&&break;done;[ -s "$f" ]&&bash "$f"||echo '下载失败，请重新粘贴同一命令'

安装后查看节点：
reality-fast info

如果Xshell断开，后台会继续，不要重复安装。重连后查看：
cat /root/reality-v11-install.done
显示0代表安装、鉴权和真实传输测试全部成功。

v11行为：
- 从零安装可独立完成全部配置。
- 从v10升级会沿用UUID、REALITY密钥、端口和伪装站，原导入节点无需更换。
- v11启动成功后停用v10运行服务，避免端口冲突，但v10全部文件保留。
- v11启动失败时自动尝试恢复v10服务。
- HY2 v9服务不删除、不停止。
- 移除net.ipv4.tcp_notsent_lowat=16384限制，恢复无人为上限的发送队列。
- 根据内存使用16–128MB TCP窗口，低配VPS不会直接套用大内存档位。
- Xray policy bufferSize=0与XRAY_RAY_BUFFER_SIZE=0，优先使用Vision splice零拷贝路径。
- 开启BBR/fq、TCP Fast Open、SACK/DSACK、MTU探测、GRO/GSO/TSO。

同一台云端测试机的同轮32MiB结果：
- v10：1768.8 Mbps
- v11：1850.5 Mbps
- 本轮提升：约4.6%

必须说清：这证明参数瓶颈已移除，不代表你的跨境线路也会获得相同带宽。如果v11在你本地仍然很慢，瓶颈就是VPS端口限速、TCP回程、物理距离或Windows TCP接收窗口，服务端REALITY参数无法继续将物理线路变快。
