# WhatsApp官方Cloud API + 本地开源AI服装外贸业务员

版本：**改进点—D盘完整8B断点续传防卡死 v8**。本版本从v6重新改进，v6、v7及更早版本全部保留。

## 一步启动

解压后双击 `一键安装部署_Windows.bat`。安装器会把运行副本放在 `D:\WhatsAppLocalAI`，随后产生的Node.js、Ollama、完整8B模型、缓存和临时下载全部只写入这个D盘目录。没有D盘时会停止，不会改用C盘。

## v8针对本次问题的改进

- 不扫描、不迁移、不清理C盘已有模型或程序。
- 使用Ollama官方完整Windows便携包，没有删减运行组件。
- 使用完整 `qwen3-vl:8b` 视觉模型，约6.1GB。
- Node.js与Ollama文件下载卡住超过60秒会自动重新连接，并从D盘 `.part` 文件继续。
- 模型下载120秒没有活动时自动重启下载进程；Ollama保留已完成和未完成分片并继续下载。
- 模型各分片分别显示百分比，百分比变小可能表示切换到新分片，并非整包重新开始。
- 修复v7中不存在模型的删除命令引发的控制台句柄错误。

账号本人仍需完成Cloudflare和Meta官方安全授权。本地AI不收模型调用费，程序不会主动发送超过24小时窗口的付费模板消息。
