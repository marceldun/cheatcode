HY2单协议 v9（完整新建副本）
改进点：撤销v7/v8可能在高延迟、丢包线路上引起持续拥塞的激进参数，改用标准BBR、保守QUIC窗口、10秒保活和300秒空闲超时，并强制服务器忽略客户端错误带宽申报。v8及以前版本均保留，没有覆盖或删除。

唯一安装命令：
u='https://raw.githubusercontent.com/marceldun/cheatcode/main/install_fast_proxy_v9.sh';f=/tmp/install_fast_proxy_v9.sh;rm -f "$f";if ! command -v curl >/dev/null 2>&1&&! command -v wget >/dev/null 2>&1;then if command -v apt-get >/dev/null 2>&1;then apt-get update -y&&apt-get install -y curl ca-certificates;elif command -v apk >/dev/null 2>&1;then apk add --no-cache curl ca-certificates;elif command -v dnf >/dev/null 2>&1;then dnf -y install curl ca-certificates;else yum -y install curl ca-certificates;fi;fi;for x in "$u" "https://ghfast.top/$u" "https://gh-proxy.com/$u";do if command -v curl >/dev/null 2>&1;then curl -4fL --connect-timeout 10 --max-time 180 --retry 3 "$x" -o "$f";else wget -T 180 -O "$f" "$x";fi&&[ -s "$f" ]&&break;done;[ -s "$f" ]&&bash "$f"||echo '下载失败，请重新粘贴同一命令'

Xshell因旧代理被重启而断开时，后台安装不会停止，不要重跑。重新连接后只看：
cat /root/sb-fast-v9-install.done
显示0代表安装和真实传输测试成功。查看节点：sb-fast info

v9行为：
- 从零安装或从v8升级都会完成全部配置。
- 从v8升级时沿用原HY2密码，但生成独立v9状态文件。
- 强制忽略客户端错误带宽申报，防止发送量超过真实线路容量。
- 标准BBR，8MB流窗口，32MB连接窗口，最多128并发流。
- 10秒保活，300秒空闲超时，减少NAT映射过早失效。
- 不创建外部网站探针；v5-v8旧探针均备份后永久mask。
- sing-box进程真实退出时，systemd会在1秒后自动恢复。

必须说清：此版已消除脚本和服务端可控的已知不稳定因素，但单条HY2/UDP无法在运营商丢包、UDP限流、VPS宿主机断网时诚实保证物理线路100%零掉线。这些情况要真正无感切换，必须有第二条路径或非UDP备用协议。
