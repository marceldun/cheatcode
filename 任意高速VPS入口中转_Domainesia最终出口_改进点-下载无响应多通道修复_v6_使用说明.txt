任意高速 VPS 入口中转 → Domainesia 最终出口 v6
=================================================

v6 改进点：修复 v5 使用静默 curl 下载失败后立即退出、屏幕没有任何提示的问题。

只在 Domainesia（202.155.14.177）执行下面这一整行：

u='https://raw.githubusercontent.com/marceldun/cheatcode/main/install_chain_relay_v6.sh';f=/tmp/install_chain_relay_v6.sh;rm -f "$f";for x in "$u" "https://ghfast.top/$u" "https://gh-proxy.com/$u" 'https://github.com/marceldun/cheatcode/raw/refs/heads/main/install_chain_relay_v6.sh';do curl -4fL --connect-timeout 10 --max-time 180 --retry 3 "$x" -o "$f"&&[ -s "$f" ]&&break;done;[ -s "$f" ]&&bash "$f"||{ echo '所有下载通道均失败，未执行空脚本';exit 1;}

改进内容：
- 强制 IPv4 下载，绕过 Domainesia 当前异常 IPv6 路径。
- GitHub Raw、两个镜像和 GitHub Raw 备用地址依次自动切换。
- 下载过程显示错误和进度，不再静默。
- 必须确认脚本文件非空后才运行。
- v5 的两机自动编排、隐藏密码、两跳测试、IPv4 DNS、端口避让和原服务保护全部保留。

脚本启动后只需输入高速 VPS 的 root@公网IP；没有 SSH 密钥时再隐藏输入一次 root 密码。
v5 和所有更早版本继续保留。
