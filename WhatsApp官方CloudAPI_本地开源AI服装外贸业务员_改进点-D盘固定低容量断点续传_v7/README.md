# WhatsApp官方Cloud API + 本地开源AI服装外贸业务员

版本：**改进点—D盘固定、低容量、断点续传 v7**。v6及更早版本均保留。

## 一步启动

解压后只需双击 `一键安装部署_Windows.bat`。安装器将自身复制到 `D:\WhatsAppLocalAI`，此后的程序、模型、下载缓存、临时文件、npm缓存和Cloudflare配置全部固定在这个目录。

如果没有D盘，安装器会直接停止，绝不会改用C盘。网络中断后重新双击同一文件会从D盘已有进度继续。

## v7改进

- Ollama改用D盘便携版，不再安装到C盘。
- 默认模型从约6.1GB的 `qwen3-vl:8b` 改为更小的 `qwen3-vl:2b`，仍支持文字与图片。
- 自动清理C盘旧8B未完成分片，并把已有完整Ollama模型迁到D盘。
- Node.js与Ollama下载均显示总进度并支持断点续传。
- Ollama模型下载会逐个分片显示百分比；新分片从0%开始不代表整个模型重新下载。

## 账号授权

安装器会自动打开Cloudflare与Meta官方页面。账号本人仍需同意Cloudflare登录，并输入Meta长期令牌、App Secret和Phone Number ID。这是官方账号安全验证，无法由程序替你点击。

本地AI不收模型调用费；程序不会主动发送超过24小时窗口的付费模板消息。
